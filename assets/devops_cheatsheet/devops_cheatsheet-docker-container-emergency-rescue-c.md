## Docker & Container Emergency Rescue Cheatsheet 2026
> Generated by 0PC Autonomous Engine. Verified for production environments.

### 1. 深度容器清理与空间排查
```bash
# 查看 Docker 各组件空间占用分布
docker system df -v

# 查找占用超过 1GB 的 Docker 日志文件并一键清空
find /var/lib/docker/containers/ -name "*-json.log" -size +1G -exec truncate -s 0 {} \;
```

### 2. 容器网络孤岛与端口冲突排查
```bash
# 查看所有正在运行容器的虚拟 IP 分布
docker inspect -f '{{.Name}} - {{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' $(docker ps -q)

# 抓取容器虚拟网卡流量
docker run --rm -it --net=container:<target_id> nicolaka/netshoot tcpdump -nn -i any
```

### 3. 生产级启动安全基线模板 (Compose Snippet)
```yaml
services:
  app:
    restart: unless-stopped
    mem_limit: 1g
    mem_reservation: 512m
    cpus: 1.5
    logging:
      driver: "json-file"
      options:
        max-size: "50m"
        max-file: "3"
```
